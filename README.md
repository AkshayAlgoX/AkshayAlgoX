Integer-paise matching makes every decision. An LLM only investigates exceptions, and a rule-based validator checks each claim against the records. Split payments use an exact search that agrees with a brute-force reference on 3,000 seeded cases.

Decides whether to pay now, pay in parts or wait. An optional LLM extractor may only return schema-checked facts. `Decimal` money and a suffix-minimum search find the earliest safe payment day.

A physiology model kept in step by an unscented Kalman filter, plus a learned correction. On a locked, preregistered evaluation it beat a persistence baseline at 60 minutes. Not for clinical use.
